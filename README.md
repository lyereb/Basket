# 愤怒的章鱼 · ANGRY OCTO

一款基于 HTML5 Canvas + TypeScript 制作的休闲物理弹跳投篮游戏。玩家通过单键按压蓄力，将粉色独眼小章鱼头顶的蓝色篮球投入篮筐，篮球触碰方块、篮筐外圈与青色星柱均会产生真实物理反弹。

## 玩法特色

- **单键按压蓄力**：支持鼠标长按、手机触屏长按与键盘 `Space` 长按蓄力，松手发射；按压时小章鱼会播放 6 帧压扁动画，搭配青色→珊瑚橙蓄力条与可开关的虚线抛物线引导。
- **真实碰撞反弹物理**：固定时间步长（`1/60s` × 4 子步）确定性 2D 物理，方块碰撞、篮筐左右外圈圆形碰撞、青色星柱弹射与严格“自上而下”入筐双传感器判定。
- **10 个已校验关卡**：内置 5 个经典日落沙滩布局（长堤缺口吊筐、浮岛串跳、左高塔右细墙、中央立柱、右塔反斜高位筐）及 5 个进阶动态机关关卡（移动浮岛、升降/巡航篮筐、星柱组合），均通过自动化物理求解器验证可解。
- **完整系统**：加载页、主菜单、选关与三星评分存档、局内引导、进球庆祝与结算面板、同屏双人 1v1 模式、每日签到解锁新角色、程序化 Web Audio 卡通音效。

## 本地运行

```bash
npm install
npm run dev
```

打开浏览器访问 `http://localhost:5173/` 即可游玩（按 `R` 可快速重开当前关）。

## 构建与关卡校验

```bash
# 类型检查与生产构建
npm run build

# 自动化物理求解器验证全部 10 关可解区间
npm run verify-levels
```
